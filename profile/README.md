<h1 align="center">Tavric Labs</h1>
<p align="center"><strong>Tools and infrastructure for LLMs and agent systems.</strong></p>

We build the infrastructure around agents: running their services, connecting their tools, controlling access, and carrying useful work context between sessions and devices.

## Products

- [MCP Runtime](https://github.com/mcp-runtime/mcp-runtime) — a self-hosted Kubernetes runtime and control plane for MCP servers. Deploy and route services, govern tool access, and audit requests inside your own cluster. [Website](https://mcpruntime.org/) · [Docs](https://docs.mcpruntime.org/) · [Quickstart](https://docs.mcpruntime.org/quickstart/)
- [Cully](https://github.com/mcp-runtime/cully) — a workspace around coding agents, with session guidance, durable project memory, team handoffs, and native Self-mode mobile clients. [Website](https://cully.net/) · [Docs](https://docs.cully.net/)
- [mcp-mobile](https://github.com/mcp-runtime/mcp-mobile) — native Kotlin and Swift MCP client SDKs for mobile apps, wrapping the official MCP SDKs. [Releases](https://github.com/mcp-runtime/mcp-mobile/releases)

## Supporting projects

[Python MCP](https://github.com/mcp-runtime/py-mcp) · [MCP Auth](https://github.com/mcp-runtime/mcp-auth) · [MCP Server Fuzzer](https://github.com/mcp-runtime/mcp-server-fuzzer)

MCP Runtime remains the product name. Tavric Labs is the organization bringing these projects together.
