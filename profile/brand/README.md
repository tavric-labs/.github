# Tavric Labs icon

The organization mark is an abstract T made from interlocking structural rails: connected systems, with a clear joint and a strong silhouette at small sizes. Warm ivory and a cobalt accent sit on a dark ink background. Cully retains its own existing product icon.

- `tavric-labs-icon.png`: original generated square master, 1254 × 1254.
- `tavric-labs-avatar.jpg`: 512 × 512 upload-ready GitHub avatar, encoded from the same artwork.
- `PROMPT.md`: original generation prompt and tool provenance.

The profile README displays the icon. Setting the account avatar itself is a separate GitHub profile-settings action; committing this file does not change that setting.
